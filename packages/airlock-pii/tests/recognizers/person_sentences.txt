# Handwritten sentences for the name recognizers, with the names marked. Every name is made
# up: common given names put together with common surnames, and no one in particular.
#
# One sentence per line:   language | tags | text
#
#   [[name]]   a name the rules find, exactly these characters, with the NER off
#   {{name}}   a name the rules do not find: they have too little to go on. It counts as a
#              miss of the rules. The NER finds it, unless the sentence is tagged ner-miss.
#
# A Kazakh case suffix stays outside the brackets: the name in "Айгерімге" is "Айгерім".
# {NBSP} stands for a no-break space and {BREVE} for a combining breve, which no file of
# this project may hold as themselves.
#
# Languages: ru, kk (Cyrillic), kk-latn, mixed, en. Tags say what a sentence is there for;
# test_names_in_sentences.py counts them, so that no kind of case is dropped by accident.
#   excl:<word>   a street, place or company word next to a name that is no person
#   heldout       a name that the gazetteer does not know, on purpose (HELD_OUT in the tests)
#   beyond        the sentence has a name in {{ }}
#   ner-miss      the NER does not find that name either
#   none          the sentence has no name at all
