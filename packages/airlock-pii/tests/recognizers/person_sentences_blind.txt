# Fifty sentences written after the rules were finished, to try them on text that they were
# not shaped by.
#
# The other file, person_sentences.txt, was written first, and the rules were worked on until
# they agreed with it. It shows what the rules are meant to do, and it cannot show how they do
# elsewhere. These sentences can, a little. They were run once, on 2026-10-06:
#
#   rules only       38 of 42 names found, each with its exact span; 2 spans that are no name
#   rules and NER    41 of 42 names found; 4 spans that are no name; and twice two names with
#                    "пен" or "мен" between them reported as one
#
# The last of these was a mistake in how a span of the model is cut into names, and it was
# corrected: a word in lower case now ends a name there, as it does for the rules. With that,
# the NER run gives 40 of 42, each with its exact span, and the same 4 spans that are no
# name. Nothing else in the library or in its word lists was changed for these sentences: not
# the misses ("Ли", "Мейрамбек", a surname alone at the start of a sentence, "Арман" at the
# start of one), and not the false reports ("Толе", a street; the name a theatre carries;
# "Жаңа Тариф" and "Халық Банкі", which only the NER reports).
#
# The counts as they are now are in test_names_in_sentences.py, and a change that moves them,
# either way, shows there. Do not tune the rules to these sentences: once they are tuned to,
# they say nothing more. Add new ones instead.
#
# 2026-10-08, names, round 2: one more span that is no name, 3 with the rules and 5 with the
# NER. A given name that is also a word is now a person at the start of a sentence as well,
# when a capitalized word of which nothing is known stands next to it ("Мақсат Сейтқали
# жазды" left in clear before). "Алтын Орда базары", a market, opens a sentence with "Алтын",
# which is such a name, and "Орда" is on no list. The same two words were reported in the
# middle of a sentence before this change; now they are reported here too. Neither word was
# put on a list for it: that is the price of the rule, and this file is where it shows.
# The names found did not move: 38 and 40 of 42.
#
# 2026-10-12: one name was replaced, in "Вопрос к ... по поводу отпуска". The given name and
# the patronymic that stood there are those of a well-known person, and every name in these
# files is made up. The new one has the same shape, a given name in a Russian case with a
# Kazakh patronymic. It was chosen before it was tried, and it is found as the old one was,
# by the rules and with the NER: no count moved.
#
# One sentence per line:   language | text
# [[name]] marks every name of a person, whether or not it is found. A Kazakh case suffix
# stays outside the brackets. Every name is made up: common given names put together with
# common surnames, and no one in particular.
